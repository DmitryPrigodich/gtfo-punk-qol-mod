# GtfoPunk QoL — руководство

Клиентские удобства и исправления для GTFO (BepInEx 6, IL2CPP). [English version](GUIDE.md).

- **Только у себя:** хосту и остальным ставить ничего не нужно; баланс не меняется — можно играть с рандомами.
- Настройки: `BepInEx/config/AmDDRed.GtfoPunk.QoL.cfg`. Каждая фича — раздел с `Enabled` (включено по умолчанию,
  если не сказано иное). Неиспользуемые ключи удаляются из файла при запуске.
- `[General] RespectOtherMods = true`: фича выключается сама, если стоит известный мод с той же фичей (QoLFix,
  SkipIntro…) — без двойных патчей.
- Текст в игре: `[General] TextLanguage = auto` (как язык игры), `en` или `ru`.
- В паре с **GtfoPunk My Game My Rules** (геймплей, нужен всем), но без него тоже работает.

### Архив-терминал

Открывается с HELP и списком логов. Команды:
- `LIST` — логи всех пройденных экспедиций; `LIST R4` — одного рандауна; `LIST R4A1` — одной экспедиции.
  Таблица: CODE, NAME, LOG ID, AUDIO.
- `READ <id>` — показать лог (хватит начала ID; Tab дописывает).
- `PLAY <id>` — включить аудиолог; `STOP` — остановить.
- `CLS` — очистить, `HELP`, `EXIT` (или Esc).

Пройденность берётся из прогресса самой игры и запоминается в `BepInEx/config/GtfoPunk.Archive.txt` — рандаун,
увиденный хоть раз, остаётся в архиве.

## Исправления

| Фича | Что исправляет |
|---|---|
| BioTrackerFixes | Биотрекер не съедает заправку инструмента; старые метки сканера не висят на экране. |
| DmrReloadFix | Магазин заполняется не до конца (DMR с одним патроном). |
| DoorFoamFix | Пена пролетает сквозь щели закрытых дверей. |
| KeepFlashlight | Фонарик гаснет, когда бросаешь или ставишь предмет. |
| WeaponAnimFix | Анимация перезарядки переходит на другое оружие при быстрой смене. |
| ScoutScreamMuffleFix | Звук остаётся приглушённым после крика скаута (сбрасывается и при выходе в лобби). |

## Выключено по умолчанию

| Фича | Что делает |
|---|---|
| ScreenLiquidFilter | Убирает жидкости с экрана по категориям: `HideEnemyBlood`, `HidePlayerBlood`, `HideGoo`, `HideWater`, `HideDisinfection`, `HideInfection`. |
| NoiseRemoval | Убирает синее зерно поверх картинки (тёмные места могут стать темнее). |

## Если что-то не так

- Логи: `BepInEx/LogOutput.log`; строки QoL начинаются с имени фичи (`[Archive]`, `[MenuMusic]` …).
- Фича «ничего не делает»: проверьте её `Enabled` и не заменил ли её другой мод (в логе — "already provided by …").
